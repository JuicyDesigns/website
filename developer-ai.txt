[overview]
Juicy Designs operates a content-driven marketing website for a digital
marketing agency in Pretoria, South Africa. The site publishes service
pages, guides, research, a glossary, free SEO tools, and a blog. A public
quote-request API and MCP server allow AI agents to submit quote requests
programmatically on a user's behalf.

[public-api]
status: available
description: A REST/OpenAPI endpoint and an MCP server (Streamable HTTP) that submit a free, no-obligation quote request. No price is returned; a custom proposal follows within four working hours.
openapi_spec: https://juicy-designs-quote.black-voice-76e6.workers.dev/openapi.json
mcp_endpoint: https://juicy-designs-quote.black-voice-76e6.workers.dev/mcp
tools: get_quote - inputs: name, email, service, project_summary, consent_to_contact (required); optional: company, phone, budget_range, timeline

[authentication]
No authentication is required for the public quote API or MCP server.
The get_quote tool requires the consent_to_contact field to be true,
reflecting the end user's explicit consent to be contacted (POPIA).
